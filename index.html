3D Encounter Gallery

Three pilot scenes built with Three.js. Each loads in your browser, no install. Drag to orbit, scroll to zoom, click the action buttons to interact. These use existing 2D character images as billboards — true 3D models would need ~$0.20 + 30 sec per character via Meshy.ai or Tripo3D.

How this scales: these are 2D images on 3D billboards (always face camera) in a real 3D environment with proper lighting, fog, particles, and orbit controls. Total page size < 1 MB. To get TRUE 3D models (rotatable from any angle): pipe each canon image through Meshy.ai or Tripo3D (~$0.20 + 30 sec per character). Then load the .glb in the same Three.js scene. Foundry VTT also has a 3D Canvas module if you want a complete prebuilt VTT instead of building your own.
